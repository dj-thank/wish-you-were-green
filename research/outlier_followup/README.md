# 残る 2,007 天体の個別スペクトル確認

このディレクトリは、過去のレビュー待ち集合 2,344 天体から、先に目視確認した 337 天体を除いた **2,007 個の entity key** を扱う追加監査である。現在の単位検証済みスペクトルを使って 126 ページの一覧図を作り、各パネルに個別の観察メモを対応させる。最終的な完了状態は [review_completion.json](review_completion.json)、全対象の個別台帳は [individual_review.csv](individual_review.csv) を参照する。

ここでの「確認」は、準備した一覧図を実際に開き、曲線または明示的な表示不可理由を一件ずつ確認したという意味である。物理的な異常の原因、スペクトル同士の観測上の独立性、未確認の単位が解決したという意味ではない。元の 337 天体の 22 枚の図、修正前・修正後の既存結果は変更していない。

## 原データと単位をどう確認したか

[retrieval_plan.json](retrieval_plan.json) は、表示に必要な 3,041 個の原データ SHA、取得 URL、入力行、既存キャッシュの場所を記録する。開始時に 16 個が同一 SHA で存在し、新たに必要だったのは 3,025 個だった。最大 4 並列で取得し、最終的に全 3,041 個、632,365,109 bytes を原 SHA と照合した。単位未確認の記録は、この比較図を作るために一括取得していない。

取得ログ [retrieval.jsonl](retrieval.jsonl) は試行の履歴である。Gaia XP の 1 件に一時的な HTTP エラーがあり、限定した後続再試行で元の SHA のデータを回収した。そのためログの行数はユニークな入力数より 1 多い。集計は **SHA ごとの最後の結果**を用いる。[retrieval_summary.json](retrieval_summary.json) の最終未取得数は 0。

図の生成時には、原 bytes の SHA を再確認してから再パースした。古い中間 NPZ の値だけを信用していない。SDSS の直接取得 FITS と MWDD の書き出し形式は、それぞれの入力形式で読み込み、既存の `flux_conventions.as_flux_lambda` を通して単位の根拠と数値 SHA を検証する。検証された (F_\nu) は

\[
F_\lambda = F_\nu\,c/\lambda^2,
\qquad \operatorname{ivar}_{\lambda}
=\operatorname{ivar}_{\nu}/(c/\lambda^2)^2
\]

として変換する。ここで波長は Å、(c) は Å/s で整合させる。形がそれらしくなるという理由だけで変換を決めていない。

現在の保存済み校正が受理されている場合は、その係数から乗算因子を適用し、逆分散も対応して変換する。その後、符号を保持した非ビン化の画素で現在の色を再計算した。3,041 記録のすべてで保存された (u,v) との差が許容値 (10^{-7}) 以下で、最大差は **(7.0062\times10^{-13})** だった。これは現在の計算と原データの対応が再現するという検証であり、測光校正の物理的な誤差がその値まで小さいという意味ではない。

## 図の読み方と限界

各ページは 4 × 4 の 16 パネル、最後のページのみ 7 パネル。Gaia source ID または保存された名前を表示し、凡例の `D`、`S`、`XP` はそれぞれ DESI、SDSS、Gaia XP、続く数字は元の 0 始まりの入力行番号である。SDSS の直接 FITS 取得は破線、MWDD の書き出しは実線。`nu->lambda` は検証済みの単位変換を行った記録、`no sigma` はこの書き出しに誤差帯を作る情報がないことを示す。

各曲線は 5,200–5,500 Å の中央値で独立に規格化した。今回の 3,041 曲線では別の規格化領域へのフォールバックは使っていない。したがって、この図は相対的なスペクトル形状を比較するもので、絶対フラックス変動を測る図ではない。

- 線は表示専用の **20 Å の算術平均**。数値の色計算にこのビン化は使わない。
- 細い縦線は、そのビンに含まれる有効な元の書き出し画素の最小値・最大値。負の有効画素も保持する。
- 入力の有限値、正の逆分散、既存の標準的な狭い空輝線マスクを通過した画素を描く。「全画素」はこのクリーニング後の可視域画素を指す。原データの不明な flag 列を新しい除外ルールにしていない。
- 誤差帯は、入力にある独立画素の標準誤差をビン平均へ伝播したもの。Gaia XP の係数共分散、再標本化による画素間相関、測光校正の不確実性はこの帯には含まれない。
- 元の最小値・最大値と供給された誤差帯を縦軸にすべて含める。巨大な誤差で連続光がつぶれる場合も、主図だけから値を切り捨てない。
- 360–830 nm の表示位置と 20 Å ビン幅からの目視の波長見積もりは概略値である。狭いピークの波長や線名は、元の書き出し格子に戻って確かめる必要がある。

`eligible` は現在の機械的条件を通過したという意味である。十分な校正精度、全可視域の実測、独立な観測、物理的な異常の確認を保証しない。50 Å を超える欠損も [record_dispositions.csv](record_dispositions.csv) に追確認用のフラグとして残すが、この監査で既存の計算や適格判定を変更していない。

## 目視から具体的な追確認へ

広い範囲で一致する地上スペクトルの周囲に、XP の青端・赤端の大きな振動が重なる例が多い。こうした表示上の振動から新しい吸収線や変動を直ちに推定しない。一方、単位を確認した後も複数装置の広い波長域の形が異なる例は残る。例示を [followup_priorities.csv](followup_priorities.csv) に、次に調べる内容と元の行番号付きで保存した。この表は実見から選んだ例示で、各パターンの発生率を数えたものではない。

- **Gaia 2586182156053386240（40/13）**：DESI 981 と XP 980 は中央付近から赤へ低下するが、SDSS 978/8781 は赤側まで高い。色や傾斜の不一致を、観測時期、位置、開口への混入、校正のどれが説明し得るか調べる対象。
- **Gaia 3647608024725171968（59/5）**：DESI 5451 と XP 5450 に対し、SDSS 8510 の 400–480 nm の相対連続光が低く平坦。元の SDSS 応答と観測情報を確認する対象。
- **Gaia 3646912496889350784（59/3）**：二つの直接 SDSS 記録 9667/9677 の青側の形が異なり、一方は DESI 4268 に近い。図で同じ色の線を区別するだけでなく、行番号を使った数値照合と観測識別子の確認が必要。
- **XP の 655 nm 付近の目立つ表示ピーク**（31/8、32/11、33/11 など）：既存の Gaia 分類・変光情報を先に確認し、独立スペクトルや XP 共分散を調べてから物理的に解釈する。

この最後の確認は、目視後に実施した。前半の 3 天体と後半の 2 天体を公式 Gaia DR3 に照合すると、選んだ 5 例すべてにすでに `VARIABLE` のフラグがあった。1951666884868218112、2096274276193099136、4565045873343899136 は公開分類器の `CV`、5589261737965864832 は `S`、2208124536065383424 には取得した分類表のクラス値がなかった。[catalogue_matches.csv](gaia_additional_features/catalogue_matches.csv) と [照合根拠](gaia_additional_features/results.json) に取得結果・原 URL・書き出し格子の確認を保持する。分類器のラベルやスコアを確定した天体種や事後確率とは扱わず、5 例の選択結果を母集団全体の比率にも拡張しない。少なくとも、これらを変光やピークの新規発見として数える前に既存情報を踏まえて位置づけ直せる。

### 原画素・位置・表示範囲の追加診断

これらの目視所見の一部には、すでに次の診断を追加している。

1. [display_diagnostics/](display_diagnostics/) は、曲線のある 1,684 天体すべてについて、全範囲と平均線の中央的な幅の比を検査した。比 ≥8 の 30 天体に、全範囲と明示的な拡大表示を並べた 8 枚を追加し、[30 天体の実見記録](display_diagnostics/visual_review.ja.md) を保存した。元の 126 枚は不変で、この 30 天体を追加の独立天体数には数えない。
2. [spike_diagnostics/](spike_diagnostics/) は、目視で選んだ狭い特徴を元の書き出し格子と供給誤差へ戻して調べる。局所画素の削除と補間による色の変化は感度実験であり、正しいマスク幅や物理的な線の有意性を決める手続きではない。図の概略波長と元格子の波長が違った場合は、担当メモにも訂正を残す。
3. [association_diagnostics/](association_diagnostics/) は、実見で選んだ連続光の不一致について、原 SDSS FITS の観測日時とファイバー位置を読み、Gaia の固有運動で観測 epoch に位置を伝播する。小さな位置差は混入や校正誤差がないことの証明ではなく、Gaia の `NOT_AVAILABLE` も一定光度の証明ではない。
4. [targeted_diagnostics/README.md](targeted_diagnostics/README.md) は、前回の強い外れ値のうち狭い特徴の例と公式 Gaia 情報を照合する。すでに存在する分類を見落として新規発見と呼ぶことを避けるための確認である。
5. [representation_calibration/README.md](representation_calibration/README.md) は、同じ SDSS 原観測だと原画素で証明できる 3 組を取り出し、未較正同士・現在の個別状態・同じ既存補正を使う場合を比較した。1311674353544358912 と 1025033665052512000 では、受理閾値の分岐や PS1 への代替較正の有無で片方だけに補正がかかり、同じ観測の表現間にそれぞれ $\Delta uv=0.01360,0.01517$ の差が生じていた。共通の既存補正では約 $6.16\times10^{-7},1.45\times10^{-6}$ に縮小する。これは装置間の独立な不一致ではなく、同じ観測の処理状態の差として説明できる。2586182156053386240 は両表現とも未較正で一致しており、XP / DESI との約 0.034 の差は残る。LHS2086 は対応する MWDD SDSS 表現がなく保留とした。

これらは原因の候補を具体的に絞るための検査であり、目視から自動的にデータを削除したり、現在の色や候補の順位を書き換えたりしていない。

## 再現・整合性検証

`build_followup.py census` が差集合と全記録を作り、`fetch --workers 4` が SHA を指定して原データを取得し、`generate` が単位確認・色再計算・描画を行う。原データ本体は既存の survey cache に置き、取得元とハッシュをこのディレクトリへ記録する。元ファイルをネットワークから再取得する工程と、コミットされた根拠だけで検証できる工程を分けている。

目視メモの統合と原 bytes の再確認は、レポジトリのルートから次で実行できる。

```bash
.venv-research/bin/python research/outlier_followup/complete_review.py --verify-raw
```

CI では 3,041 個の原キャッシュの存在を要求せず、`verify_outputs.verify(root)` がコミット済みの根拠を確認する。検証するのは、差集合 2,007 と全 4,370 行の一致、全 3,041 曲線の単位・適格性・色再現結果、全 126 画像と個別メモの SHA の一致、旧 337 天体との集合分離、旧 22 画像の不変性、取得ログの SHA ごとの最終成功結果である。

画像を再生成する研究は別の checkout で行い、変更後の画像に過去の実見メモを未確認のまま付け替えない。今回の生成物と個別メモは、完了 JSON のハッシュを基準として追跡する。
