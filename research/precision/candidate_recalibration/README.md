# PS1 gri較正と、未使用zバンドへの予測

ここでは既存screenの27候補に対する追加検証を保存する。`standardized_colours.csv` と25個のNPZは、Swanの外部PS1測光を出典付きで加えたgri再較正の結果である。`heldout_z.py` はその保存済みスペクトルを変更せず、較正に使っていないz等級を予測する。候補選択に含まれる暫定identityや、元のscreenの系統誤差はこの比較だけで解消しない。

## zバンドの実測結果

[27天体の個別結果](heldout_z.csv)、[計算法・全入力SHA256・サマリー](heldout_z.json)、[残差図](heldout_z.png) を保存した。2026-10-18の実行では25天体で比較でき、2天体は正確なIDで一致するSwan外部測光と較正スペクトルがない。欠測行も削除していない。

残差は `予測z − 観測z` と定義する。中央値は−0.01608 mag、範囲は−0.08967～+0.09904 mag、絶対値が0.05 magを超えるものは10/25、0.10 magを超えるものは0/25だった。これは残差の大きさの記述であり、発見の有意度や採否の閾値ではない。

## 積分と欠損の扱い

[speclite](https://speclite.readthedocs.io/en/latest/api.html) 1.0.0の `panstarrs-z`、すなわち [Tonry et al. 2012](https://doi.org/10.1088/0004-637X/750/2/99) に基づくPS1固有応答を用いる。SDSS zへ置き換えない。保存済みのFλを光子重み付きで積分してAB等級を求める。元NPZの負fluxを切り上げず、有限fluxかつ有限IVAR>0の画素を用いる。これらのMWDD由来NPZには元DESI bitmaskがないため、IVARの品質判定が全ての元フラグを再現するとは仮定しない。

25スペクトルは3600–9824 Åで、zの全応答7840–9520 Åを含む。フィルタの両端を有効画素が挟むことを要求し、内部の欠損だけを線形補間する。通過応答に占める無効画素の割合（平坦なFλに対する光子重み）は最大2.511%、有効画素間の最大間隔は21.6 Åだった。残差を見る前に定めた点検条件「欠損応答>5%または間隔>50 Å」に該当する対象はなかった。この条件通過は校正精度の保証ではない。

欠損をゼロで埋めるstressでは線形補間から最大0.02172 mag、最近傍の有効値で埋める方法では最大0.000529 mag変わった。前者も後者も欠損の真のfluxを測ったものではなく、誤差上限でもない。元の画素を上書きせず、感度診断として列を分けた。PS1 yは全応答8960–11010 Åのうち赤端が欠けるので、全25天体で予測を行わない。外挿や黒体による補完は行っていない。

## 誤差と独立性

SwanのPS1列は未消光補正の観測AB等級として用いる。誤差には公表側の追加floorが既に含まれるため、z比較で同じfloorを再追加しない。gri較正時の最小誤差0.02 magは元の較正手順の条件として保持する。[原論文・DR1/DR2直接照会による定義確認](../../literature/swan_photometry_definition.md)

図の棒はSwan zの公表誤差だけであり、全誤差ではない。CSVにはスペクトルの画素誤差だけを伝播した値も記録した。specliteの積分を線形演算として評価し、補間で同じ端点が再利用される依存は重みに反映する。一方、画素間の元共分散、griの較正パラメータ共分散、共有するPS1系統誤差、非同時性、空・大気の残差は含まれない。zは較正アンカーとして未使用でも、PS1という同じサーベイに属し、iの赤端とも波長域が重なる。単純な残差÷誤差のnσ、有意確率、変光の確定は報告しない。

## 再実行・由来

repo rootで実行する。

```bash
.venv-research/bin/python research/precision/standardized_candidate_photometry.py
.venv-research/bin/python research/precision/candidate_recalibration/heldout_z.py
```

2番目は保存済み入力だけで再実行できる。各NPZを `derivative_manifest.json` のSHA256に照合し、較正時と同じ測光行であることも確認する。元の外部表、対象行、元スペクトル、派生NPZ、入力CSV、応答曲線、実行コードのハッシュを記録した。外部表は [Swan et al. 2026](https://arxiv.org/html/2609.04314v1) の [externalData_1.0](https://cygnus.astro.warwick.ac.uk/phsdaj/WhiteDwarfs/Tables/DESI_DR1_externalData_1.0.csv.gz)、圧縮ファイルSHA256は `15c3cfa5fc1fc17328620ab9ed46ea714c1ad9436f2adb5e1b4b053099c4f91a` である。データの帰属、DESIの利用条件と指定謝辞は [文献調査の記録](../../literature/README.md) と [DATA_ACKNOWLEDGMENTS.md](../../literature/DATA_ACKNOWLEDGMENTS.md) を参照する。

### 元入力の保存とCIで判明した依存の修正

追加検証の最初のCI実行で、25本の較正に使った元スペクトルのうち19本が未追跡のローカル取得キャッシュにしか存在しないことが判明した。この19本を `raw_sources/*.csv.gz` に可逆圧縮して保存した。[対応表](raw_sources/manifest.json) には元の `raw_path`、取得URL・日時、原文と圧縮ファイルそれぞれのSHA256・バイト数、および既存の派生manifestのSHA256を記録している。元の原文、解析値、`derivative_manifest.json` の履歴上のパスやコードハッシュは変更していない。

`scripts/verify_research_extension.py` は、この19本について常に保存済みgzipを読み、圧縮SHA256と展開後の元SHA256を両方確認する。キャッシュがローカルに残っていても代用しない。他の6本は既存の追跡済み原文を照合する。検証レポートの `verified_file_sha256` は実在する保存ファイル、`verified_lossless_original_sha256` は展開後に確認した元のパスと原文SHA256を示す。

修正は、Gitの追跡対象だけを別ディレクトリへ書き出した状態で検証する。ローカル取得キャッシュや仮想環境をその書き出しに含めず、書き出し先の外を作業ディレクトリとして、書き出した検証器に `--root` でその場所を渡す。これにより、元の作業フォルダにしかない入力への依存を検出する。
