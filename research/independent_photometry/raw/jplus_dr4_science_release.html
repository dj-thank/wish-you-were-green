J-PLUS Data Release DR4

The J-PLUS DR4 Data Release (November 2025) (J-PLUS-DR4) comprises 2563 J-PLUS fields observed in twelve optical bands amounting to ~5000 deg2. J-PLUS DR4 is based on images collected from November 2015 to February 2025 by the JAST80 telescope.

For quick access to the archive and the User's Manual, you can use the following links.

DATA ACCESS: https://archive.cefca.es/catalogues/jplus-dr4

DATA ACCESS MANUAL: Download manual here

PDF DECOM. LEPHARE: Download software here (v1.1)

PDF DECOM. LEMONNADE: Download software here (v1.0)

GLOBAL MASKS: https://archive.cefca.es/catalogues/vo/siap/jplus-dr4/get_global_masks (only registered users)

Scope

Total area covered 4950.66 deg2 (4437.49 deg2 after masking)
Image size 11730x11730 pixels
Image pixel scale 0.45 arcsec
Total number of fields 2563
Number of objects in dual catalogue ~96.9 million (~47.3 million with MAG_AUTO(rSDSS)≤21)
Number of objects with estimations of photo-z (with their full PDFs) ~79.2 million
Number of detections in single catalogue ~786.5 million
Size of the database ~730 GB
Number of Single Frames 96182
Tile Images Total Size (compressed) ~2.05 TB
Single Frames Total Size (compressed) ~9.06 TB
