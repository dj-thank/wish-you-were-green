Table jplus.Filter

Table that contains information about the filters.

Columns

Name Type Units UCD Description
FILTER_ID short meta.id;instr.filter Identifier of the filter
name char meta.id;instr.filter Name of the filter
wavelength int Angstrom em.wl.central Central wavelength of the filter
width int nm instr.bandwidth Filter amplitude
kx double phys.absorption Extinction coefficients. Estimated using the star-pair method in Yuan et al. 2013.
abs_zp_offset double mag phot.mag;arith.zp Zero point offsets already applied to the images and photometry of each band. They are derived from the WD stellar loci regression, following the method described in López-Sanjuan et al. 2024 and after anchoring r-band to that of PanSTARRS PS1 as an absolute zp offset common for all the filters.
abs_zp_offset_err double mag stat.error;phot.mag;arith.zp Absolute zero point uncertainties to be added in quadrature to the photometric errors. They are determined from the uncertainties of the WD stellar locus regression and the global anchoring of DR4 to PS1 r-band, which is conservatively assumed to be 5mmag, as in López-Sanjuan et al. 2024.
color_representation char Filter HTML color representation
