Table jplus.MagABDualObj

Table that contains the main parameters of the astronomical objects detected in the images. The object detection and aperture definition is performed in a reference band ('rSDSS') and the measurements are done in each filter using SExtractor (Dual Mode). Array columns (type[]) contains measures for each filter (NULL if the image in the filter is not available). Enumeration 'jplus' can be used to refer filter positions in the array. Magnitude data is adjusted by the image Zero Point and is in magnitude AB units.

Flags Values

Several flags are comprised in the field flags as a sum of powers of 2 coded in decimal. For example, an object close to an image border may have FLAGS = 16, or perhaps FLAGS = 8 + 16 + 32 = 56.

Value Name Description
1 close neighbors The object has neighbors, bright and close enough to significantly bias the photometry, or bad pixels (more than 10% of the integrated area affected)
2 blending The object was originally blended with another one
4 saturation At least one pixel of the object is saturated (or very close to).
8 truncated The object is truncated (to close to an image boundary)
16 aperture incompleted Object's aperture data are incomplete or corrupted
32 isophotal incompleted Object's isophotal data are incomplete or corrupted
64 memory overflow deblending A memory overflow occurred during deblending
128 memory overflow extraction A memory overflow occurred during extraction

Masks Flags Values

Several mask flags are comprised in the field mask_flags as a sum of powers of 2 coded in decimal.

Value Name Description
0 not masked Not inside a mask
1 window Object is outside the window frame
2 bright star Object is bright star or near one
4 artifact Object masked due to nearby artifact

Variability Flags Values

Several variability flags are comprised in the field var_flags as a sum of powers of 2 coded in decimal.

Value Name Description
0 not variability No known variability
1 known variable The object might be a known variable. More information is stored in the DualObjVariable table, which indicates which known variable it corresponds to.
