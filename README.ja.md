# Additional white dwarf colour candidates from public spectra

## 公開スペクトルから見つけた、追加の白色矮星の色の候補

[English](README.md) · **日本語**

公開観測データを取得して実際に計算し、**WD J0913+4434 と WD J0429−0354 を、追加の淡い黄緑色白色矮星候補として抽出しました。** さらに、ピンク色の WD J1329+0033 と、通常の黒体の色から外れた黄色の WD J1323−0129 を報告しています。

いずれも**既に知られている星**です。新規性を検討しているのは、人間の視覚に対応する色度の計算と、その検証です。これは**探索段階の、査読を受けていない研究ノート**であり、星そのもの、新しい大気の物理機構、世界的優先権を確定したという主張ではありません。

**企画・管理:** Shota Moriwaki  
**解析日:** 2026年10月18日 · **版:** 0.1.0  
**リポジトリ:** [dj-thank/pale-yellow-green-white-dwarf-candidate](https://github.com/dj-thank/pale-yellow-green-white-dwarf-candidate)

## 主要な結果

以下の代表値はすべて、**DESIスペクトルをPan-STARRSのg・r・i測光に合わせて再校正**し、CIE 1931の2°標準観測者の等色関数で積分したものです。

| 候補 | Gaia DR3 source_id | 色の候補 | sRGB | Duv | 条件付き95% Duv区間 |
|---|---|---|---|---:|---|
| **WD J0913+4434** | 818833831355548928 | 淡い黄緑 | #F1FFC9 | +0.01901 | +0.01695 ～ +0.02112 |
| **WD J0429−0354** | 3204436719718449280 | 淡い黄緑 | #F8FFDC | +0.01281 | +0.01197 ～ +0.01365 |
| WD J1329+0033 | 3711047662972690688 | ピンク | #FFC1CF | −0.02265 | −0.02481 ～ −0.02048 |
| WD J1323−0129 | 3638333660492606976 | 黒体から外れた黄色 | #FFE86A | +0.02348 | +0.02094 ～ +0.02597 |

丸める前のx・y・u・v、校正パラメータ、出典URLとハッシュは [headline_candidates.csv](results/headline_candidates.csv) にあります。方法と解釈の全体は[日本語報告書](docs/report.ja.md)と[英語報告書](docs/report.en.md)に記載しています。

**DuvはCIE 1960のu,v色度図で、黒体の色の軌跡から測った符号付きの距離です。正だから緑色とは限りません。** J1323−0129は、Duvが正でも黄色となる具体例です。距離0.01という目安は [Hollands et al. (2026)](https://doi.org/10.1093/rasti/rzag069) に合わせた比較基準であり、普遍的な色の識別限界や発見の有意水準ではありません。

### データから支持されること

黄緑色の2候補は、DESIとGaia XPの元係数から再構成したスペクトルで、平均の色が同じ側に残ります。異なる測光による校正、スペクトルの形、近傍天体、既存の大気モデルも検討しました。[Swan et al. (2026)](https://arxiv.org/html/2609.04314v1) の公式表では、主要候補のDESIへの混入推定はガウス型PSFを仮定した計算の範囲でごく小さくなっています。これは支持材料ですが、あらゆる混入光の厳密な上限ではありません。

主要候補は、Hollands et al. (2026) の表3～6にある**236の重複しない名称**の一覧に含まれません。さらに、そのDZ親標本の**231天体**とも照合しました。調べた先行研究では、これらの対象のCIE色度やsRGBの報告は見つかりませんでした。ただし、この限定された調査で、未索引文献や未公表の計算を含むすべての先行研究の不存在を証明したわけではありません。分類、温度、組成、吸収機構などの既存の知見は原著者に帰属します。[先行研究の監査表](novelty/novelty_evidence.csv)に、資料ごとの根拠と限界を残しています。

### 結果を使うときに必要な留保

- **DESIの区間は条件付きです。** 公開画素誤差、測光誤差、0.02等の測光誤差下限を使った6,000回の乱数試行から求めています。未知の画素間相関、流束校正の系統誤差、混入光、探索後の選択効果を完全には含みません。
- **Gaiaだけで色名を確定してはいません。** 係数誤差から波長間の共分散を伝播しました。Gチャンネルが最大となる形式的な試行割合は、全基底でJ0913が85.0%、J0429が82.3%、推奨基底数への切り詰めでは77.8%と96.5%です。これらは誤差モデル内の値であり、新発見が実在する確率ではありません。切り詰めによるバイアスや、提供されていないBP/RP間の校正相関は残ります。
- **共通の測光は共通の誤差を持ちます。** 同じ測光で校正した2本のスペクトルの確率を、独立だとみなして掛け合わせることはできません。
- **色の見え方には観測者と表示の条件があります。** エネルギー流束密度Fλ、明所視の標準観測者、規格化したsRGB/D65を使っています。色順応のモデルや星間減光の補正によって、星表面の本来の見え方まで推定したわけではありません。
- **探索的な研究です。** 数千の記録と複数の処理条件を調べました。探索全体の偽発見率や有意度は算出していません。対照標本やコードの再現確認を通過しても、この限界は消えません。
- **有力そうに見えても残さなかった例があります。** LP616−53は近い伴星と大きな測光混入のため格下げしました。誤った測光を使うと極端な青が生じる例も除外しました。全順位表は、確定した新発見の一覧ではありません。

詳しくは[Gaia共分散の検証](mwdd/gaia_validation/README.md)、[研究の誠実性について](docs/research-integrity.md)、[報告書](docs/report.ja.md)をご覧ください。

## 探索した範囲

| 構成 | 記録された範囲 |
|---|---|
| 取得時点のMWDDカタログ | 163,279行 |
| MWDDからのスペクトル取得 | 主にQ/Z型と比較対象の5,548カタログ天体、8,505記録 |
| SDSSからの直接取得 | Q/Z型1,343観測とDA/DB/DC対照54観測、合計1,397本のFITS |
| 合同走査 | **9,902スペクトル記録**。同じ天体・同じ観測の重複を含む |
| 形式・波長条件を満たしたもの | 9,023記録 |

MWDDの8,505記録のうち、数値的に異なるスペクトルは8,502本です。SDSSの直接取得分とMWDDにも同じ観測が含まれ得ます。Q/Z型を意図して多く集め、公開アーカイブの網羅性にも制約があるため、宇宙の白色矮星のうち何%がこうした色かは推定していません。件数と定義は [screen_summary.json](results/screen_summary.json) にあります。

## 主要結果を再現する

**Python 3.12**を使います。GitとPython 3.12がある環境で、次を実行してください。

```bash
git clone https://github.com/dj-thank/pale-yellow-green-white-dwarf-candidate.git
cd pale-yellow-green-white-dwarf-candidate
python3.12 -m venv .venv-colour
.venv-colour/bin/python -m pip install -r requirements-core.txt
.venv-colour/bin/python scripts/verify_reproduction.py --with-controls
```

Windowsでは、仮想環境内のPythonのパスを `.venv-colour\Scripts\python.exe` に読み替え、環境作成時にはPython 3.12を使ってください。

依存パッケージを導入した後の検証では、**天文データの追加ダウンロードは行いません。** 原ファイルのハッシュと変換後配列を照合し、主要4候補のDESI色を再計算し、同梱したGaiaの平均スペクトル・共分散を検証し、**54本のSDSS対照の原データから再計算**します。この科学検証のプロセスではネットワーク接続を禁止しています。

この小規模な検証は、同梱したGaia再構成結果から始めます。Gaiaの校正基底からの再構成や、全標本の走査までを毎回実行するものではありません。元係数と、より深い再構成の手順は[Gaia検証の説明](mwdd/gaia_validation/README.md)にあります。DESIの不確かさの乱数試行も別の計算です。`--with-controls` を付けない短い実行では、対照については保存済み結果の照合だけを行い、その違いを出力に明記します。

数値許容差、環境、検証成功の意味は [reproducibility.en.md](docs/reproducibility.en.md) に記載しています。成功は、保存された計算と入力の整合を示すもので、天文学的な新規性や系統誤差の不存在を証明するものではありません。

### 任意：固定した全標本を再走査する

同梱の固定マニフェストから、9,902記録の計算全体を再実行できます。取得段階では公開アーカイブへの接続と約2 GBのスペクトル取得が必要になる場合があり、原ファイルのSHA256が一致することを確認してから使用します。

```bash
.venv-colour/bin/python download_frozen_spectra.py --workers 4
.venv-colour/bin/python run_full_screen.py
```

この経路は `project_io.py` を通して、同梱の圧縮した入力・測光マニフェストを読みます。同梱していないMWDDの全カタログを別途必要とするものではありません。再現するのは**保存済みの選択標本**であり、現在のカタログから新しい標本を選び直す処理ではありません。全走査は保存済み圧縮表を残したまま非圧縮の結果表を作り、集計を更新します。小規模な作業ディレクトリをそのまま保ちたい場合は別のチェックアウトで実行してください。上記の主要結果のオフライン検証には、この全取得は不要です。
